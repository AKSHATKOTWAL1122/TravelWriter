# 01.1 Project setup

Feature: 01 Backend foundation
Depends on: none

Goal: a backend that starts, answers a health check, and has a working test setup, so every later spec can be built and tested.

Behavior
- `backend/` is a Python 3.12+ project managed with `uv` (`pyproject.toml` + `uv.lock`).
- Dependencies for this spec only: `fastapi`, `uvicorn`; for development: `pytest`, `httpx2` (needed by FastAPI's test client; plain `httpx` is deprecated there, see ISSUE-041).
- Code lives in the package `backend/storymaker/`; the FastAPI app object is `storymaker.main:app`.
- `GET /health` returns `200` with `{"status": "ok"}`.
- The server listens on all network interfaces (`0.0.0.0`, port `8000`), so phones on the same Wi-Fi can reach it (ISSUE-015).
- Tests live in `backend/tests/`; `conftest.py` provides a shared `client` fixture (FastAPI test client).
- The project root (`StoryMaker/`) is a git repository with default branch `main`.
- A root `.gitignore` covers `.venv/`, `__pycache__/`, `.pytest_cache/`, `.env` and `.DS_Store`.

Acceptance
- [x] `cd backend && uv sync` installs without errors.
- [x] `uv run uvicorn storymaker.main:app --host 0.0.0.0 --port 8000` starts the server.
- [x] `curl http://localhost:8000/health` returns `200` and `{"status":"ok"}`.
- [x] Manual: `http://<laptop-ip>:8000/health` opens in a phone browser on the same Wi-Fi (confirmed by the user).
- [x] `uv run pytest` passes, with a test for `/health` that uses the `client` fixture.
- [x] The run and test commands are listed under "Commands" in CLAUDE.md.
- [x] `git status` works at the project root, and ignored files (`.venv/`, `.env`) don't show up.

Out of scope: settings/env vars (01.2), database (01.3), any trip or post endpoints, Docker, deployment.
