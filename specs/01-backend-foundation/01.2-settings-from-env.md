# 01.2 Settings from the environment

Feature: 01 Backend foundation
Depends on: 01.1

Goal: one place where the backend reads its settings from environment variables or a local `.env` file, with safe defaults, so no secret or machine-specific value is ever written in code.

Behavior
- `storymaker/config.py` defines a `Settings` class (using `pydantic-settings`) and `get_settings()`, which returns one shared instance.
- Lookup order: environment variable → `backend/.env` (if present) → default.
- Naming: the app's own settings start with `STORYMAKER_`; third-party keys keep their standard names.
- Settings in this spec (both already fixed by CLAUDE.md):
  - `GEMINI_API_KEY`: optional, empty by default. The app must start without it; only LLM calls need it (10.1).
  - `STORYMAKER_MODEL`: default `gemini-2.5-flash`.
- `backend/.env.example` lists every setting by name: secrets left empty, defaults shown as comments.
- Later specs that need a setting add it to `Settings` and `.env.example` together. This rule goes into CLAUDE.md.
- Tests never read the developer's real `.env` or shell variables: a shared test fixture hides them automatically (ISSUE-043).
- New dependency: `pydantic-settings`.

Acceptance
- [x] With no `.env` and no variables set, the app starts, `/health` works, and the model setting is `gemini-2.5-flash`.
- [x] An environment variable changes a setting; a value in `backend/.env` is used when no variable is set; the variable wins when both exist.
- [x] `uv run pytest` passes even though this machine's shell has a real `GEMINI_API_KEY`, and no test sees that key.
- [x] `backend/.env.example` exists with no secret values; `backend/.env` is ignored by git.
- [x] CLAUDE.md's Rules say where new settings go.

Out of scope: settings not listed here (each later spec adds its own), checking the key with Google, mobile app settings (04.2).
Later: none

  - Later settings are added by their own specs through this mechanism: data folder (01.3), media folder (03.3), link-signing secret (03.8), LLM mock switch (10.3), parallel limit (11.5).
  - Mobile settings are separate (04.2).
