# 01.4 API conventions

Feature: 01 Backend foundation
Depends on: 01.1, 01.3

Goal: one set of rules every endpoint follows, so the ~30 endpoints in 02–12 and the app's API client (04.2) all look and behave the same (ISSUE-040).

Behavior
- **Paths:** every endpoint is registered on one shared router with the prefix `/api`, using plural nouns and nested IDs, e.g. `POST /api/trips`, `GET /api/trips/{trip_id}/posts`. `/health` stays at the root.
  - Endpoint modules live in `storymaker/endpoints/`. Every module there is loaded at startup, so an endpoint spec only adds a file and never edits `main.py` (ISSUE-053).
- **Bodies:** JSON with `snake_case` field names. File uploads (03.4, 03.5) use multipart form data.
- **Errors:** every error response has the shape `{"error": {"code": "<snake_case>", "message": "<a sentence a person can read>"}}` with a fitting HTTP status. The `code` is for the app's logic; the `message` is safe to show on screen. Endpoints raise `ApiError(status, code, message)`.
  - Invalid request → `422 validation_error`, with a message naming the bad field.
  - Unknown path → `404 not_found`.
  - Any unexpected failure → `500 internal_error`, with a generic message and no internal details.
- **Times:** ISO-8601 in UTC with milliseconds and a `Z`, e.g. `2026-10-10T14:30:00.123Z`. The same fixed-width format is used in API responses **and** in the database, so text order equals time order. Incoming times must carry a time zone; they're converted to UTC (ISSUE-036). Times without one are rejected.
- **IDs:** random, URL-safe strings from `new_id()`, never counting numbers (1, 2, 3).
- Each endpoint spec lists its path, fields and error codes. A code is reused when the meaning is the same, e.g. `not_a_member`.

Acceptance
- [x] A route on the shared router answers under `/api/…` (test-only route); `/health` still answers at the root.
- [x] `ApiError(404, "trip_not_found", "…")` returns `404` with exactly `{"error": {"code": "trip_not_found", "message": "…"}}`.
- [x] A bad request body returns `422 validation_error`, with a message naming the field.
- [x] An unknown path returns `404 not_found` in the same shape.
- [x] An unexpected exception returns `500 internal_error` with no stack trace or internal details in the response.
- [x] `utc_now_iso()` returns the format above; the parser converts `+05:30` times to UTC and rejects times without a zone.
- [x] `new_id()` gives unique random strings (10,000 in a row, no repeats).
- [x] 01.3's `applied_at` uses the same time format (ISSUE-045, rule 5).
- [x] Every module in `storymaker/endpoints/` is loaded at startup without editing `main.py`; 02.3's `POST /api/trips` answers (ISSUE-053, rule 5).
